# Map data

All files here are generated by `scripts/build-geo.mjs` from open data. Nothing is hand-drawn.

| File | What it is | Source | Licence |
| --- | --- | --- | --- |
| `world.geojson` | Country shapes, simplified to about 4 km | [Natural Earth 1:10m admin-0, **India point of view**](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_10m_admin_0_countries_ind.geojson) | Public domain |
| `regions/<CC>.geojson` | States, provinces, departments and counties for the pilot countries, simplified to about 400 m, with ISO 3166-2 codes | [Natural Earth 1:10m admin-1](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_10m_admin_1_states_provinces.geojson) | Public domain |
| `../../data/reference/cities.json` | City coordinates used to place exam venues, each tagged with its ISO 3166-2 region | [GeoNames cities15000](https://download.geonames.org/export/dump/) | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) — attribution: GeoNames |

**Why the India point of view.** Natural Earth publishes boundary variants for different national points of view. GOV View serves Indian users and Indian public notices, so the world layer follows India's official depiction of its boundaries. Other disputed areas follow Natural Earth's defaults for that view. Boundaries are for orientation only. They are not a statement about any territorial claim.

**What the shapes mean.** Country and state shapes are for navigation and filtering. Highlighting a state doesn't mean every place in it is covered by an opportunity. Exam-venue pins come only from venues named in a notice. Each pin says whether its position is exact or a city centre. Online and unannounced venues never get a pin.

## Rebuilding

```bash
mkdir -p /tmp/geo && cd /tmp/geo
curl -LO https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_admin_0_countries_ind.geojson
curl -LO https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_admin_1_states_provinces.geojson
curl -LO https://download.geonames.org/export/dump/cities15000.zip && unzip cities15000.zip
cd - && node scripts/build-geo.mjs /tmp/geo
```

Antarctica is left out: it wraps the South Pole, which the globe renderer can't fill, and it has no recruitment authorities.
