# GOV View privacy

GOV View is a static site. It has no account server and does not collect an applicant profile. Eligibility details, including optional nationality and OCI status, and saved notices are stored in your browser. They are not included in shared links and do not sync between devices. Clearing browser storage removes them from that browser. JSON exports you choose to download remain under your control.

Photo and signature resizing, when available, runs in the browser. Selected images are not uploaded to GOV View. Avoid entering information for someone else without their consent. Only enter date of birth when needed for a notice’s age check; users who need parental or guardian help under local law should ask for it. GOV View does not ask for identity-document uploads.

Visiting the site sends ordinary web requests to the hosting provider. The provider sees request information such as IP address, URL, and browser headers and may retain access logs under its own policy. Opening official notices or application links takes you to a separate authority website with its own privacy practices. GOV View does not control those websites.

The project uses no advertising tracker, hosted eligibility API, or analytics service in the current static build. Future features require this notice to be updated before launch.
